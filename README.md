# webdev-course-Nexatech

Fundamentos de Desarrollo Web: un curso introductorio de **HTML y CSS** para estudiantes de secundaria (12 a 17 años) sin experiencia previa en programación.

- ⏱️ **Duración total:** ~60 minutos, en 8 videos cortos
- 🎯 **Público objetivo:** estudiantes de 12 a 17 años
- 📚 **Prerrequisitos:** ninguno
- 🛠️ **Herramientas:** solo un navegador web

---

## 🚀 Cómo empezar (configuración)

**No hay nada que instalar ni que configurar, y tampoco hace falta crear cuentas.**

1. Elige una lección en la tabla de abajo.
2. Mira el video.
3. Haz clic en el enlace de **Práctica**. Se abrirá CodePen en tu navegador con el código de inicio ya cargado.
4. Escribe tu código y mira el resultado al instante.

Si te atascas, abre la carpeta `completed-examples` de esa lección para ver la solución.

### Requisitos

Un navegador web moderno:

- Google Chrome
- Mozilla Firefox
- Safari
- Microsoft Edge

## 📂 Estructura del repositorio

Cada lección tiene su propia carpeta con la misma organización:

```
lessonN-nombre/
├── starter-files/        # Código de inicio para la práctica (lo que se carga en CodePen)
│   ├── starter.html
│   └── starter.css       # (desde la lección 4, cuando empezamos con CSS)
├── completed-examples/   # Solución de la práctica, tal como queda al final del video
│   ├── completed.html
│   └── completed.css
└── scripts/              # Guion del video de la lección
    └── lessonN-script.md
```

| Carpeta | Para qué sirve |
|---------|----------------|
| `/starter-files` | El punto de partida de cada práctica, con comentarios que indican qué escribir. |
| `/completed-examples` | El resultado final esperado, para comparar o para consultar si te atascas. |
| `/scripts` | Los guiones con los que se grabaron los videos. |

El plan completo del curso está en [`upc-pre-202620-1asi0730-16712-Nexatech-course-plan.md`](./upc-pre-202620-1asi0730-16712-Nexatech-course-plan.md).
