# 🎓 Guión — Lección 1: ¿Qué es un sitio web?

---

## 🎬 Introducción — ¿Qué estamos viendo?

> "¡Hola a todos! Bienvenidos a nuestro curso de desarrollo web."

"Antes de empezar a escribir código, vamos a responder una pregunta muy sencilla:

**¿Qué ocurre realmente cuando abrimos un sitio web?**"

"Probablemente todos usamos páginas web todos los días. YouTube, Wikipedia, Instagram, tiendas online, páginas de noticias... pero normalmente simplemente hacemos clic, escribimos una dirección y listo."

"Hoy vamos a mirar un poco detrás de escena para entender **qué estamos construyendo cuando hacemos una página web**."

---

## 🌐 ¿Qué es un sitio web?

"Empecemos por lo básico.

Una **página web** es un documento que nuestro navegador puede interpretar y mostrar de forma visual."

"Un **sitio web**, por otro lado, puede estar formado por varias páginas relacionadas entre sí."

"Por ejemplo, una tienda online podría tener:

- una página de inicio,
- una página para cada producto,
- una página de contacto,
- y otras secciones."

"Cuando visitamos una de estas páginas, el navegador se encarga de mostrarnos su contenido."

> **Nota visual:** Mostrar una página web sencilla y señalar diferentes elementos: título, texto, imágenes, botones y enlaces.

"Pero aquí viene lo interesante:

**¿Cómo sabe el navegador qué es un título, qué es un párrafo, dónde aparece una imagen o cómo debe verse un botón?**"

"Para eso utilizamos principalmente dos tecnologías que vamos a aprender durante este curso:

**HTML y CSS.**"

---

## 🧱 HTML: la estructura y el contenido

"Primero tenemos **HTML**."

"HTML significa *HyperText Markup Language*, o **Lenguaje de Marcado de Hipertexto**."

"Y aquí hay una diferencia importante: HTML **no es un lenguaje de programación tradicional**."

"HTML sirve para **organizar y describir el contenido de una página web**."

"Podemos utilizar HTML para decirle al navegador:

- esto es un título,
- esto es un párrafo,
- esto es una imagen,
- esto es un enlace,
- esto es una lista."

> **Nota visual:** Mostrar ejemplos sencillos de elementos HTML.

```html
<h1>Mi primera página</h1>

<p>Hola, estoy aprendiendo desarrollo web.</p>
```

"El navegador puede interpretar estas etiquetas y entender que tenemos un título y un párrafo."

"Podemos imaginar HTML como **la estructura de una casa**."

"Las paredes, las puertas, las habitaciones... HTML determina qué elementos existen y cómo están organizados."

---

## 🎨 CSS: la apariencia

"Pero tener una estructura no significa que nuestra página tenga que verse bonita."

"Ahí entra **CSS**."

"CSS significa *Cascading Style Sheets*, o **Hojas de Estilo en Cascada**."

"CSS se utiliza para controlar **cómo se ve nuestro contenido**."

"Podemos cambiar colores, tamaños, fuentes, espacios, posiciones y muchas otras características."

> **Nota visual:** Mostrar el mismo HTML primero sin estilos y después con CSS.

"Por ejemplo, podemos tener este título:"

```html
<h1>Mi primera página</h1>
```

"HTML nos dice que esto es un título."

"Pero podemos utilizar CSS para decidir que sea grande, que tenga determinado color, que utilice una fuente concreta o que tenga cierto espacio alrededor."

"Por eso podemos imaginar que:

- **HTML es la estructura de la casa.**
- **CSS es su diseño y decoración.**"

"Ambos trabajan juntos, pero cumplen funciones diferentes."

---

## 🔍 ¿Qué ocurre cuando visitamos una página?

"Entonces, ¿qué sucede cuando escribimos una dirección en nuestro navegador?"

"El navegador obtiene los archivos necesarios para construir la página y los interpreta."

"Entre esos archivos podemos encontrar nuestro HTML y nuestros estilos CSS."

"El navegador utiliza el HTML para entender **qué contenido debe mostrar y cómo está organizado**."

"Después utiliza CSS para determinar **cómo debe verse ese contenido**."

"Finalmente, nosotros vemos el resultado en pantalla."

> **Nota visual:** Mostrar el proceso de forma sencilla:

```text
HTML + CSS
    ↓
Navegador
    ↓
Página web
```

"Y esto es justamente lo que vamos a aprender a hacer."

"Vamos a escribir nuestro propio HTML y CSS, abrirlo en un navegador y ver cómo nuestras instrucciones se convierten en una página web."

## 🕵️ Actividad: Explora una página web

"Antes de terminar, vamos a hacer una pequeña actividad."

"Abre cualquier página web que utilices normalmente."

"Puede ser una página de noticias, una tienda, Wikipedia o cualquier otro sitio."

"Ahora intenta identificar visualmente algunos elementos."

**Busca:**

- un título,
- un párrafo,
- una imagen,
- un enlace,
- algún botón,
- y diferentes elementos que parezcan estar agrupados.

"No necesitas saber todavía qué etiqueta HTML representa cada cosa."

"Simplemente observa la página y empieza a pensar:

**¿Qué partes forman esta página y qué función cumple cada una?**"
