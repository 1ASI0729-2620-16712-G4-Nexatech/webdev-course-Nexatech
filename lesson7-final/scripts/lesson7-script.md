# 🎓 Guión — Lección 7: Mejorando y organizando nuestra página

---

## 🎬 Introducción — Nuestra página ya funciona

> "Hasta ahora hemos aprendido a construir una página utilizando HTML y CSS."

"Ya tenemos contenido, imágenes, enlaces, listas, colores, espacios y bordes."

"Pero cuando terminamos una página, todavía hay algo importante que hacer: **revisarla**."

"Una página web no solo debe funcionar. También debe ser **clara, fácil de leer y consistente**."

"En esta lección vamos a hacer una revisión rápida de nuestro proyecto y veremos algunos pequeños cambios que pueden mejorar mucho el resultado final."

---

## 🧹 Organizar nuestro código

"Primero vamos a mirar algo que no siempre podemos ver directamente en la página: **nuestro código**."

"Cuando una página empieza a crecer, nuestro HTML y nuestro CSS pueden tener muchas líneas."

"Por eso es importante mantenerlos organizados."

"Podemos utilizar espacios y sangrías para que sea más fácil reconocer qué elementos están relacionados."

Por ejemplo:

```html
<h2>Mis intereses</h2>

<p>
    Me gusta aprender desarrollo web.
</p>

<ul>
    <li>Programación</li>
    <li>Videojuegos</li>
    <li>Música</li>
</ul>
```

"El código sigue funcionando exactamente igual."

"Pero ahora podemos identificar rápidamente dónde comienza cada sección y qué elementos pertenecen a ella."

> **Nota visual:** Mostrar primero el código desordenado y después el mismo código correctamente indentado. Preguntar al grupo cuál de los dos resulta más fácil de leer.

"La organización del código no cambia necesariamente el resultado visual."

"Su objetivo es que **nosotros podamos entender y modificar nuestro propio trabajo con mayor facilidad**."

---

## 🏷️ Utilizar nombres y contenido claros

"También debemos pensar en los nombres y textos que utilizamos."

"Nuestros títulos deberían explicar claramente qué contiene cada sección."

Por ejemplo:

```html
<h2>Mis videojuegos favoritos</h2>
```

"Es mucho más claro que utilizar simplemente:"

```html
<h2>Sección 2</h2>
```

"Lo mismo ocurre con los textos de nuestra página."

"Si alguien visita nuestro sitio, debería poder entender rápidamente de qué trata cada parte."

> **Nota visual:** Mostrar dos versiones de una misma sección y señalar cómo los títulos ayudan a comprender la información.

"Una buena página no debería obligar al visitante a adivinar qué significa cada cosa."

---

## 🎨 Revisar la apariencia

"Ahora podemos mirar nuestra página como si fuéramos visitantes."

"Preguntémonos algunas cosas sencillas."

- ¿Los textos se pueden leer fácilmente?
- ¿Los títulos se distinguen de los párrafos?
- ¿Los colores combinan entre sí?
- ¿Hay suficiente espacio entre las diferentes partes?
- ¿Las secciones siguen una organización similar?

"Por ejemplo, si utilizamos un estilo determinado para nuestros títulos principales, podemos mantener una idea similar en el resto de la página."

> **Nota visual:** Mostrar el proyecto completo en el navegador y señalar el título principal, subtítulos, párrafos, listas e imagen.

"La idea no es llenar nuestra página de colores y bordes."

"Es utilizar los estilos para **ayudar a organizar y comunicar la información**."

---

## 🔍 Una revisión rápida

"Antes de considerar terminada nuestra página, podemos hacer una pequeña revisión."

> **Nota visual:** Mostrar esta lista en pantalla mientras el expositor la recorre.

```text
✓ ¿El contenido está organizado?

✓ ¿Los títulos describen correctamente cada sección?

✓ ¿El texto es fácil de leer?

✓ ¿Los colores son consistentes?

✓ ¿Hay suficiente espacio entre los elementos?

✓ ¿El código está ordenado?
```

"Si encontramos algo que podemos mejorar, este es el momento de hacerlo."

"Muchas veces un pequeño cambio, como mejorar un título, agregar espacio o corregir un color, puede hacer que una página se entienda mucho mejor."

---

## 🧠 Una última idea: revisar también es parte de crear

"Cuando desarrollamos una página web, terminar de escribir el código no significa necesariamente que el trabajo haya terminado."

"También tenemos que **probar, observar y revisar**."

"Podemos mirar nuestro proyecto desde dos puntos de vista:"

```text
Código
  ↓
¿Está organizado y es fácil de entender?

Página
  ↓
¿Es clara, legible y consistente?
```

"Estas revisiones nos ayudan a mejorar nuestro trabajo antes de considerarlo terminado."
